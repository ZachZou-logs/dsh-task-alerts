# 任务提醒（Task alerts）

长任务跑到一半，人离开座位去做别的事了——这个插件就是在这种时候把你叫回来。

## 什么时候会通知

| 时机 | 通知标题 |
| --- | --- |
| 一轮任务正常结束 | 任务完成 |
| 停下来等你回答提问 | 等待你的回答 |
| 停下来等你批准工具调用 | 需要你的授权 |
| 停下来等你确认方案 | 等待方案确认 |

通知正文带上会话标题，例如「重构登录模块 已完成这一轮」。点击通知会把 DSH 窗口切到前台。

同一时刻只保留最后一条通知，连续触发不会堆叠成一串。

## 什么时候不通知

- **默认 8 秒以内的快速回复**。问一句「这个函数干嘛的」，不该弹通知。
- **本来就是你在操作的那一刻**。你刚点完确认、刚回答完问题，不会再补一条「等待你」的通知。
- 同一次等待不会因为你切换窗口而重复提醒。

## 调整阈值

插件**没有可视化设置表单**，阈值写在插件自带的 `cordis.patch.yml` 里：

```yaml
config:
  minSeconds: 8          # 少于这么多秒不提醒；0 = 每轮都提醒
  lingerSeconds: 20      # 通知横幅保留秒数
  silentOnFinish: false  # true = 只提醒「等待你操作」
```

改完保存后，在插件页把这个插件**卸载再重新安装**即可生效。
